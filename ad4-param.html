練習 19 (2)　定数 c を動かしてみる

① 予想する② 動かして確かめる③ 理由を言葉にする

動かすもの

y=x²+4x+c
=(x + 2)²-4+c
(−1 ≦ x ≦ 0) の c を動かします。

オレンジの点線が軸 x = −2 です。c をどれだけ動かしても、この線は動きません。しかも軸は定義域 −1 ≦ x ≦ 0 の 外 にあります。だから頂点の値は答えにならず、両端だけを調べればよいことになります。

c を変えると、最小値をとる x の値は変わると思いますか。

予想をノートに書いてから開いてください。
軸は定義域の外。最小値はいつも左端 x = −1 でとる。頂点は答えにならない。
